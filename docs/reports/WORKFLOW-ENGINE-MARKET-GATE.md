# Workflow Engine Market Gate (CBM-019)

**Last updated:** 27 July 2026 (Europe/Vienna)
**Scope:** Hatchet, Temporal, Trigger.dev, Restate, Inngest, Prefect, Windmill, Kestra, Dagster, Airflow, Argo, Dapr
**Rule:** evidence-only preflight. No runtime benchmark numbers are created, inferred, or used to pick a runtime winner in this lane.

## Scoring Contract

CBM-019 now scores exactly 20 workflow-engine features per candidate. Each scored feature is 0-10, with a 200-point ceiling per engine. Evidence status remains separate from numeric score:

- `verified`, `partial`, and `blocked` can carry numeric scores.
- `pending` is unscored (`null`), not an invented zero-performance result.
- `legal_review` is unscored (`null`) and marks license/open-core review needs; it is not an automatic product block unless actual self-host pilot terms prohibit the required use.

The full deterministic contract is in `benchmarks/orchestration/WORKFLOW_GATE_SCORING_SCHEMA.md`.
